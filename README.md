# Заметки — PWA-ежедневник для iPhone

Приложение ставится на экран «Домой» через Safari и работает без интернета.
Данные хранятся на телефоне и синхронизируются с твоей Google-таблицей.

## 1. Выложить на GitHub Pages

1. На github.com нажми **New repository**. Название: `notes`, видимость: **Public**
   (бесплатный Pages работает только для публичных репозиториев; твоих заметок в коде нет —
   они живут на телефоне и в твоей таблице). Нажми **Create repository**.
2. На странице пустого репозитория нажми ссылку **uploading an existing file**.
3. Перетащи из Finder всё содержимое папки `Notes`: `index.html`, `app.js`, `styles.css`,
   `sw.js`, `manifest.webmanifest`, папку `icons`. Нажми **Commit changes**.
4. **Settings → Pages**. Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)**, **Save**.
5. Через 1–2 минуты приложение откроется по адресу `https://ЛОГИН.github.io/notes/`.

## 2. Установить на iPhone

Открой адрес в **Safari**, нажми «Поделиться» → «На экран Домой».

## 3. Подключить Google-таблицу (рекомендую)

1. Создай **новую** Google-таблицу, например «Заметки».
2. **Расширения → Apps Script**, удали всё и вставь код из `google-apps-script/Code.gs`.
3. В строке `const SECRET = '…'` впиши свой длинный пароль. Сохрани (💾).
4. **Начать развёртывание → Новое развёртывание** → шестерёнка → **Веб-приложение**.
   «Выполнять как»: **Я**, «У кого есть доступ»: **Все**. Разверни и выдай доступ
   («Дополнительно» → «Перейти…» — это твой собственный скрипт).
5. Скопируй URL веб-приложения (заканчивается на `/exec`).
6. В приложении: ⚙️ → вставь URL и секрет → «Синхронизировать сейчас».
   Скрипт сам создаст листы «Папки», «Дела», «Заметки».

После изменения кода скрипта: **Управление развёртываниями → ✏️ → Версия: новая** (URL останется прежним).

## Обновление приложения

Замени изменённые файлы в репозитории (Add file → Upload files) и увеличь номер `CACHE`
в `sw.js`. На телефоне новая версия подхватится со второго открытия.

## Что внутри

- **Сегодня** — ежедневник: все дела на день из всех папок, галочки, листание по дням стрелками
  или по неделе. Незакрытые дела прошлых дней собираются сверху — «Всё на сегодня» переносит их разом.
- **Перенос**: смахни дело вправо → выбери день (завтра, в понедельник, через неделю, любая дата).
- **Папки** — MOST, Возвраты, Мой Instagram, Мой Telegram, Дом и семья (можно добавлять свои,
  менять цвет и значок). Внутри — дела и заметки.
- **Календарь** — месяц с точками по дням, дела выбранного дня, добавление на любую дату.
- **Входящие** — всё, что добавлено без папки. Сюда позже подключим автосортировку через ИИ.
- Кнопка **+** — быстрая запись: дело или заметка, дата, папка. Несколько строк = несколько дел.
- Резервная копия в JSON (⚙️ → Данные).
