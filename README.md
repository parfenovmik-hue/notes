# Заметки — PWA-ежедневник для iPhone

Приложение ставится на экран «Домой» через Safari и работает без интернета.
Данные хранятся на телефоне и синхронизируются с твоей Google-таблицей, файлы из тем — с Google Диском.
Напоминания приходят на заблокированный экран.

## 1. Выложить на GitHub Pages

1. На github.com нажми **New repository**. Название: `notes`, видимость: **Public**
   (бесплатный Pages работает только для публичных репозиториев; твоих заметок в коде нет —
   они живут на телефоне, в твоей таблице и на Диске). Нажми **Create repository**.
2. На странице пустого репозитория нажми ссылку **uploading an existing file**.
3. Перетащи из Finder: `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest`
   и папку `icons` (вместе с `icons/folders`). Исходные картинки логотипов и папку
   `google-apps-script` загружать не нужно. Нажми **Commit changes**.
4. **Settings → Pages**. Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)**, **Save**.
5. Через 1–2 минуты приложение откроется по адресу `https://ЛОГИН.github.io/notes/`.

## 2. Установить на iPhone

Открой адрес в **Safari**, нажми «Поделиться» → «На экран Домой».
Дальше открывай приложение только с иконки — уведомления работают именно так.

## 3. Подключить Google-таблицу (нужно для синхронизации, файлов в облаке и уведомлений)

1. Создай **новую** Google-таблицу, например «Заметки».
   Проверь часовой пояс: **Файл → Настройки → Часовой пояс** (по нему считается время напоминаний).
2. **Расширения → Apps Script**, удали всё и вставь код из `google-apps-script/Code.gs`.
3. В строке `const SECRET = '…'` впиши свой длинный пароль. Сохрани (💾).
4. Вверху в списке функций выбери **setup** и нажми **Выполнить**. Google попросит доступы —
   разреши («Дополнительно» → «Перейти…» — это твой собственный скрипт). Функция включает
   проверку напоминаний каждые 5 минут и создаёт на Диске папку «Заметки — вложения».
5. **Начать развёртывание → Новое развёртывание** → шестерёнка → **Веб-приложение**.
   «Выполнять как»: **Я**, «У кого есть доступ»: **Все**. Разверни.
6. Скопируй URL веб-приложения (заканчивается на `/exec`).
7. В приложении: ⚙️ → вставь URL и секрет → «Синхронизировать сейчас».
   Скрипт сам создаст листы «Папки», «Темы», «Дела», «Файлы».

После изменения кода скрипта: **Управление развёртываниями → ✏️ → Версия: новая** (URL останется прежним).

## 4. Включить уведомления

В приложении, открытом с экрана «Домой» (iOS 16.4+): ⚙️ → **Включить уведомления** → разреши.
Нажми **Проверить** — через несколько секунд придёт тестовое уведомление.

- **Утром** — план на день (по умолчанию 9:00), **вечером** — что не закрыто (можно включить).
- **Напоминание о деле**: у дела выбери дату → «Напомнить в» и время. Приходит с точностью до 5 минут.

## Обновление приложения

Замени изменённые файлы в репозитории (Add file → Upload files) и увеличь номер `CACHE`
в `sw.js`. На телефоне новая версия подхватится со второго открытия.

## Что внутри

- **Сегодня** — ежедневник: все дела на день из всех папок и тем, галочки. Свайп по неделе
  влево/вправо — следующая/предыдущая неделя, стрелки — по одному дню. Незакрытые дела прошлых
  дней собираются сверху — «Всё на сегодня» переносит их разом.
- **Дела**: смахни вправо — перенести на другой день, влево — закрепить сверху,
  удерживай и тяни — поменять порядок.
- **Папки** — сетка как на экране «Домой»: удерживай папку (или «Изменить»), чтобы перетащить
  в любую ячейку. Сверху — поиск по всем папкам, темам и делам.
- **Темы** внутри папок — как в iOS Заметках. Первая строка — название. Кнопка **Aa**:
  Название / Заголовок / Подзаголовок / Основной текст / Моноширинный, жирный, курсив,
  подчёркнутый, зачёркнутый, цветной маркер, списки (•, –, 1.), отступы, цитата.
  Чек-лист: Enter — новый пункт, Enter на пустом — выход из списка. У пункта можно поставить
  дату (значок календаря справа) — он появится в «Сегодня». Фото и файлы — кнопками в панели.
- **В папке**: поиск по темам; тему смахни вправо — закрепить, влево — удалить,
  удерживай и тяни — свой порядок.
- **Жесты везде**: сверху вниз от заголовка — в «Сегодня», от левого края вправо — назад.
- **Календарь** — месяц с точками по дням, дела выбранного дня.
- **Входящие** — всё без папки. Сюда позже подключим автосортировку через ИИ.
- Кнопка **+** — быстрая запись: дело или тема, дата, папка и тема. Внутри папки «+» сразу создаёт тему.
